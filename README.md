# WebStudio

Навчальний проєкт з курсу **HTML and CSS Fundamentals for User Interface Design 2.0** — односторінковий сайт вебстудії.

## Поточний стан

Реалізовано HTML-структуру сторінки:

- шапка з логотипом, навігацією та контактами;
- головний блок із заголовком і кнопкою `Order Service`;
- розділ переваг студії;
- розділ команди з фотографіями, іменами та посадами;
- підвал із коротким описом студії.

Сторінка використовує семантичні елементи HTML5, якірні посилання, посилання для електронної пошти й телефону. CSS-стилі та JavaScript наразі не додані. Кнопка `Order Service` поки не має обробника дії.

## Запуск

1. Завантажте або клонуйте репозиторій.
2. Відкрийте [index.html](./index.html) у браузері.

Встановлювати залежності чи виконувати збірку не потрібно. Для роботи достатньо браузера та текстового редактора. Для автоматичного оновлення сторінки під час редагування можна скористатися локальним сервером редактора, наприклад Live Server.

## Перевірка

- Перевірте відображення чотирьох фотографій команди.
- Перевірте переходи навігації до відповідних блоків сторінки.
- Перевірте посилання електронної пошти й телефону за наявності відповідних програм на пристрої.

Файл `.gitignore` виключає локальні налаштування IDE, системні й тимчасові файли.
